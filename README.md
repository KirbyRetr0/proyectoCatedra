# Pokémon Bank — LIC941, Fase 1

Prototipo **HTML5 + CSS3 + Bootstrap 4.0 por CDN** (se requiere internet para cargar Bootstrap). Abrir `index.html` en el navegador. El enlace de acceso y los botones de operación son navegación ilustrativa, **no** validan el PIN, no procesan pagos ni actualizan saldo/historial.

## Estructura
- `index.html`: PIN.
- `acciones.html`: menú principal.
- `deposito.html`, `retiro.html`, `saldo.html`, `servicios.html`: operaciones visuales.
- `historial.html`, `graficos.html`: consultas visuales.
- `css/styles.css`: diseño responsive.
- `docs/flujo.mmd`: diagrama Mermaid; pegar en https://mermaid.live para exportar una imagen para Word.
- `docs/Informe_Fase_1.docx`: borrador del informe.

## Evidencias que el grupo debe producir
1. Ejecutar `git init`, `git add .`, `git commit -m "Fase 1: interfaces"`; capturar terminal y `git log --oneline`.
2. Crear repositorio remoto en GitHub, conectar con `git remote add origin URL`, `git branch -M main`, `git push -u origin main`; capturar repositorio real y compartir con docente.
3. Capturar cada pantalla en navegador de escritorio y móvil y anexar al Word.
4. Agregar portada con integrantes, docente y sección; revisar documento y practicar defensa.

## Preparación de librerías (siguiente fase)
Investigar y preparar al menos dos ejemplos de SweetAlert, jsPDF, Chart.js y ValidateJS según la interpretación del docente; se incluye un plan en el Word. **No se presentan como funciones implementadas en Fase 1**, dado que el alcance es HTML/CSS.
